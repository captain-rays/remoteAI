# Remote AI iOS Client Design

**日期：** 2026-09-03  
**状态：** 已批准  
**首版平台：** iOS 17+、macOS 14+

## 1. 产品目标

构建一个 iPhone 客户端，通过安装在单台 Mac 上的常驻 Agent，远程操控电脑中已登录的 Codex CLI 和 Claude Code。用户可以切换 AI、查看并继续各自的日常会话和项目会话、处理权限请求、切换工作目录、浏览 Mac 文件，并在明确操作下上传或下载文件。

首版通过互联网工作，不要求局域网直连。网络层使用 Cloudflare Tunnel 转发 WSS/HTTPS，并在其上增加设备级端到端加密。所有 AI 凭据与真实会话数据仍由 Mac 上的本地 CLI 管理。

## 2. 已确认的产品约束

- 电脑端仅支持 macOS，手机端仅支持 iOS。
- 首版只绑定一台 Mac，不支持多用户或多电脑切换。
- 操控电脑上已安装的 CLI，并继续已有本地会话。
- 当前接入 Codex 和 Claude；腾讯 WorkBuddy 暂不接入，但保留适配器扩展点。
- v1 文件浏览根目录固定为已配对 macOS 用户的 `$HOME`；即使该用户对根目录外的路径有权限，也不通过 RemoteAI 暴露。未来增加额外根目录必须单独修改设计并经过安全评审。
- 支持从手机手动上传文件到 Mac，也支持从 Mac 手动下载文件到手机。
- 绝不进行自动同步或后台文件同步。
- AI 的命令、文件和外部访问授权由手机端逐次允许或拒绝。
- 首版不做系统推送，App 仅在前台实时更新。
- 首版通过 Xcode 安装到个人 iPhone，Mac Agent 以开发模式运行。

## 3. 方案选择

采用“结构化协议优先、PTY 兜底”的适配方案。

- Codex 优先连接 `codex app-server`，使用其结构化会话、消息、工具和授权事件。
- Claude 优先使用双向 `stream-json` 输入输出，并通过原始 session ID 恢复会话。
- 后续 AI 工具优先使用官方 CLI 协议或 SDK；仅在不存在结构化接口时使用伪终端 PTY。

未采用纯 PTY 方案，因为终端字符解析容易被主题、版本和交互变化破坏，也难以可靠表达权限请求。未采用直接调用各厂商 API 的方案，因为它无法完整继承本地 CLI 的登录状态、历史会话、插件和项目环境。

## 4. 总体架构

系统由三部分组成：

1. **iOS App（SwiftUI）**：展示会话、项目、文件和授权请求，管理本地只读缓存与设备密钥。
2. **Mac Agent（Rust）**：管理连接、AI 子进程、会话索引、文件传输、审计与 Cloudflare Tunnel。
3. **Cloudflare Tunnel**：把只监听 `127.0.0.1` 的 Mac Agent 暴露为 WSS/HTTPS 服务。

Mac Agent 内部模块：

- **Connection Gateway**：配对、认证、心跳、断线重连和事件补发。
- **AI Adapter**：将不同 CLI 的会话、消息、工具调用、授权和终止操作归一化。
- **Session Index**：扫描本地会话并生成轻量索引，不复制 AI 登录凭据。
- **Project Service**：分别维护 Codex 和 Claude 的项目列表及项目会话映射。
- **File Service**：浏览文件系统、切换工作目录并执行显式上传或下载。
- **Audit Log**：记录手机发起的会话操作、授权决定和文件传输。
- **Tunnel Manager**：检测 `cloudflared` 状态并提供配置提示。

iOS 与 Mac 使用版本化 JSON 消息协议。实时消息走单条 WebSocket；大文件走分块 HTTPS 上传与下载。

## 5. 信息架构与交互

### 5.1 AI 切换

顶部提供全局切换器：`Codex | Claude`。首次启动默认 Codex，之后默认打开上次使用的 AI。切换后，聊天、项目和相关状态均只展示当前 AI 的内容，不混合两套列表。

同一既有会话不能中途更换 AI。切换 AI 后，如需继续工作，应在当前目录下为新的 AI 创建独立会话。

### 5.2 底部导航

- **聊天**：当前 AI 的日常会话。日常会话不绑定具体项目目录。
- **项目**：当前 AI 的项目列表；进入项目后展示该项目的会话，并可新建会话或浏览项目文件。
- **文件**：浏览安全文件根目录（v1 为已配对用户的 `$HOME`）；从项目进入时可自动定位到根目录内的项目目录。
- **设置**：连接、配对、安全、版本、缓存、传输和审计信息。

即使 Codex 和 Claude 指向相同目录，也分别保存各自的项目元数据与会话列表。

### 5.3 对话

- 显示当前 AI、模型、工作目录和连接状态。
- 流式展示回答、运行状态、命令、文件修改和工具调用。
- 支持发送文字、停止当前任务、从 Mac 选择上下文文件，以及从 iPhone 文件选择器上传附件。
- 权限请求以卡片展示 AI、会话、工作目录、完整命令或文件操作及风险提示。
- 首版只提供“仅本次允许”和“拒绝”，不提供永久允许。

**Claude 的实际情况（2026-09-05，claude 2.1.210）**：Claude Code 无法把权限提示转发给远程客户端。在 `--permission-mode manual` 下它不发 `control_request`，而是直接把工具调用判为失败并返回 “This command requires approval”，因此手机上的审批卡片对 Claude 永远不会出现，`git fetch` 这类命令在手机端一次也跑不成。该 CLI 也没有 `--permission-prompt-tool` 之类的转发机制。

据此，手机发起的 Claude 会话按“便利客户端、无人值守”运行，默认 `--permission-mode bypassPermissions`；`REMOTEAI_CLAUDE_PERMISSION_MODE` 可在不重新编译的情况下调回（`manual` 恢复拒绝，`auto` 逐次放行但保留工作目录沙箱）。这是明确的取舍：手机端因此没有人工闸门。Codex 不受影响——它的 app-server 会发 `item/commandExecution/requestApproval`，审批卡片按原设计工作。

### 5.4 文件

- v1 只允许浏览、预览和传输 `$HOME` 本身及其后代路径；绝对路径与根目录相对路径在 Agent 端统一规范化，根目录外路径和通过符号链接逃逸的路径一律拒绝。
- 支持路径跳转、最近目录、收藏目录、搜索和常见文件预览。
- 支持手动下载 Mac 文件到 iPhone，以及手动上传 iPhone 文件到指定 Mac 目录。
- 下载落到 App 自己的 Documents 目录，并开启 `UIFileSharingEnabled` 与
  `LSSupportsOpeningDocumentsInPlace`，使其在「文件」App 中显示为
  「我的 iPhone › RemoteAI」。不开这两个键，文件会写到手机上却无法被任何方式取用。
  传输列表显示的也是这个名字，而不是沙盒路径。
- 同名上传必须选择“保留两份”或“覆盖”，不得自动决定。
- 首版不支持在手机端直接编辑、删除、移动或重命名 Mac 文件。

## 6. 数据流与连接恢复

连接建立后，iPhone 先获取轻量索引：AI 可用状态、日常会话、项目、项目会话摘要、收藏和最近目录。只有打开具体会话时才分页加载消息及工具调用记录。

Mac Agent 保留各工具的原始会话 ID，并将工具专属事件映射为统一协议。每个实时事件带递增序号。短暂断线后，iPhone 携带最后收到的序号重连，Agent 从有限事件缓冲中补发；若缓冲已经过期，则重新读取持久历史。

Mac 离线时，iOS 只展示已缓存内容，禁止发送消息、提交授权或浏览未缓存文件。CLI 崩溃或协议不兼容时，仅禁用对应 AI，另一个 AI 与文件功能保持可用。

## 6.1 常驻运行（2026-09-05）

Agent 与隧道都以当前登录用户的 LaunchAgent 常驻，开机自启、退出即拉起：
`live.jaco.remoteai.agent` 与 `live.jaco.remoteai.tunnel`。用 LaunchAgent 而非
LaunchDaemon，是因为 Agent 要读该用户的 Codex/Claude 会话，必须以其身份、其
HOME 与登录钥匙串运行。

隧道必须是 **命名隧道**：快速隧道每次启动都换随机域名，而手机在配对时会存下当时
的地址——域名一变就得重新配对。命名隧道域名固定，配对只需一次。配合已落盘的配
对记录（`devices` 表），重启 Agent、隧道或整机都不需要再扫码。

安装、卸载、查看状态见 `scripts/remoteai-service.sh`；每台机器自己的取值（隧道
域名、模型覆盖）放在 `~/.config/remoteai/agent.env`，不进版本库，样例见
`deploy/remoteai.env.example`。

## 6.2 macOS 隐私授权（2026-09-05）

手机浏览 `~/Desktop`、`~/Documents`、`~/Downloads` 等受保护目录时，macOS 会向
Agent 弹出授权对话框；Agent 派生的 CLI 也归属于它。这是系统机制，无法在代码里
绕过，只能减少重复：

- macOS 按**代码签名身份**记录授权。cargo 产物是 ad-hoc 签名，每次重新编译哈希
  都变，授权随之失效、于是反复弹窗。安装脚本因此用固定 identifier
  （`live.jaco.remoteai.agent`）和证书重新签名，一次授权即可长期有效。
- 想彻底不弹，在「系统设置 → 隐私与安全性 → 完全磁盘访问权限」中加入
  `~/Library/Application Support/RemoteAI/bin/remote-ai-agent`，一次授权覆盖全部
  受保护目录。这等于把整个磁盘暴露给手机端，是明确的取舍。

## 7. 文件传输

文件传输采用分块 HTTPS：

- 每次传输都由用户明确选择源文件和目标路径。
- 显示文件名、大小、目标位置和进度。
- 支持取消、手动重试和下载续传。
- 上传先写入目标目录内的临时文件，校验完成后再原子替换。
- 服务端规范化和验证路径，拒绝路径穿越及非法目标。
- 不运行目录监听器，不创建同步计划，不在后台自动传输。

## 8. 安全设计

- Mac Agent 默认仅监听 `127.0.0.1`，不开放局域网端口。
- 首次配对由 Mac 显示短时有效的一次性二维码。
- 配对成功后使用设备密钥进行认证，用户可在 Mac 或 iPhone 上撤销。
- WSS 之上的业务消息再次端到端加密，Cloudflare 只负责转发。
- AI 账号凭据、Cookie、Token 和密钥不得同步到手机。
- 默认隐藏 `$HOME` 下的常见系统敏感目录，用户可以主动选择显示；显示敏感目录不会扩大 `$HOME` 安全根目录。
- 删除、覆盖文件和高风险 AI 操作必须显式确认；首版不提供永久授权。
- 审计日志记录操作类型、时间、AI、会话、目标路径和授权结果，但不记录凭据。

Cloudflare Named Tunnel 用于稳定开发地址，通常无需额外订阅，但需要用户拥有可配置的域名。Quick Tunnel 可用于临时开发测试，但地址会变化，不作为稳定配对方案。

## 9. 错误处理

- **Tunnel 断开**：显示离线状态并指数退避重连，恢复后按事件序号补发。
- **Agent 重启**：重新认证并从持久索引恢复会话状态。
- **CLI 未安装或版本不兼容**：禁用对应 AI，显示检测到的版本和处理建议。
- **CLI 子进程异常退出**：保留已收到事件，标记本轮失败，允许用户重新启动或恢复会话。
- **授权超时**：保持为待处理状态；客户端重连后重新展示，除非上游 CLI 已取消。
- **文件冲突**：阻塞写入并等待用户选择，不做自动覆盖。
- **传输失败**：保留可恢复进度或安全删除临时分块，不留下半成品目标文件。

## 10. 首版范围

### 包含

- SwiftUI iOS 客户端与 Rust macOS Agent。
- Codex/Claude 切换。
- 两个 AI 各自独立的日常会话、项目列表和项目会话。
- 新建、继续、发送消息、流式响应和停止任务。
- 手机端处理 AI 权限请求。
- 文件系统浏览、目录切换、手动上传、手动下载和常见格式预览。
- 配对、端到端加密、断线恢复、只读缓存和审计。
- Cloudflare Named Tunnel 配置说明与 Quick Tunnel 开发支持。

### 不包含

- WorkBuddy、Windows、Linux、多电脑或多用户。
- 系统推送通知和局域网直连。
- 手机端文件编辑、删除、移动或重命名。
- 自动文件同步、后台传输或冲突自动解决。
- 跨 AI 会话合并、迁移或共享。
- TestFlight、App Store 或正式 macOS 安装包。

## 11. 测试与验收

### 自动化测试

- 使用临时目录测试文件浏览、路径规范化、敏感目录提示、同名冲突和分块传输。
- 使用模拟适配器覆盖流式回复、授权、取消、CLI 崩溃和协议版本变化。
- 覆盖过期二维码、错误密钥、消息重放、乱序事件和路径穿越。
- 模拟 WebSocket 断开、Agent 重启和 Tunnel 恢复，验证消息不重复且已确认操作不丢失。

### 真实集成测试

Codex 和 Claude 各自验证：

- 读取日常会话。
- 读取项目列表和项目内会话。
- 恢复历史会话。
- 在指定目录新建会话。
- 完成一轮流式对话。
- 展示并处理一次真实授权请求。
- 停止正在运行的任务。

### 最终验收场景

用户通过蜂窝网络连接 Mac，在 iPhone 上选择 Codex 或 Claude，进入该 AI 的日常会话或项目，继续真实本地会话，处理一次授权，并主动上传和下载文件。整个过程中不会发生任何自动文件同步。
